# 🤖 BARCOOD VPN Bot

ربات تلگرام فروش سرویس VPN — کامل، فارسی و آماده استقرار.

## ✨ امکانات

### 👤 بخش کاربر
- 🛒 **خرید سرویس**: لیست پلن‌ها با جزئیات (قیمت، حجم، مدت) و خرید با کیف پول داخلی
- 📦 **سرویس‌های من**: مشاهده وضعیت سفارش‌ها و دریافت کانفیگ پس از تایید
- 💰 **کیف پول**: شارژ کارت‌به‌کارت با ارسال عکس رسید و تایید ادمین
- 🎁 **دعوت از دوستان**: لینک اختصاصی + هدیه معرف به ازای اولین خرید زیرمجموعه
- 🎧 **پشتیبانی**: ارسال پیام/عکس به ادمین و دریافت پاسخ داخل ربات
- 📚 **راهنمای اتصال**: آموزش اتصال برای اندروید، iOS، ویندوز و مک

### 👑 پنل مدیریت
- 📊 آمار زنده (کاربران، سفارش‌ها، درآمد، شارژهای در انتظار)
- 📋 بررسی سفارش‌ها: تایید و ارسال کانفیگ / رد و عودت خودکار وجه
- 💳 بررسی درخواست‌های شارژ کیف پول (تایید/رد با دکمه)
- 🗂 مدیریت کامل پلن‌ها: افزودن (گفتگوی مرحله‌به‌مرحله)، فعال/غیرفعال، حذف
- 💵 افزایش/کاهش دستی موجودی کاربران
- 📢 پیام همگانی (متن یا عکس) با گزارش ارسال و بلاک خودکار کاربران مسدودکننده

## 🚀 راه‌اندازی

### ۱) نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

### ۲) ساخت ربات و دریافت توکن

از [@BotFather](https://t.me/BotFather) در تلگرام ربات بسازید و توکن را بگیرید.

### ۳) تنظیم متغیرها

```bash
cp .env.example .env
```

سپس فایل `.env` را باز کنید و مقدارها را ویرایش کنید:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها، با کاما جدا شود |
| `CARD_NUMBER` | شماره کارت برای شارژ کارت‌به‌کارت |
| `CARD_HOLDER` | نام صاحب کارت |
| `DB_PATH` | مسیر دیتابیس SQLite (پیش‌فرض `barcood.db`) |
| `REFERRAL_BONUS` | هدیه معرف به ازای اولین خرید زیرمجموعه (تومان) |
| `MIN_CHARGE` | حداقل مبلغ شارژ کیف پول (تومان) |

### ۴) اجرا

```bash
python main.py
```

اگر پیام `BARCOOD VPN Bot started…` را دیدید، ربات فعال است ✅
در اولین اجرا دیتابیس ساخته شده و چند **پلن نمونه** به‌صورت خودکار اضافه می‌شود تا تست راحت باشد — از پنل مدیریت می‌توانید آن‌ها را ویرایش یا حذف کنید.

## 🧭 نحوه کار (جریان خرید)

```
کاربر:  خرید سرویس ← انتخاب پلن ← پرداخت از کیف پول
              ↓
ادمین:  دریافت اعلان سفارش ← «تایید و ارسال کانفیگ» ← ارسال لینک کانفیگ
              ↓
کاربر:  دریافت کانفیگ + قرارگیری در «سرویس‌های من» ✅
```

اگر سفارش رد شود، مبلغ به‌صورت خودکار به کیف پول کاربر برمی‌گردد.

## 🗂 ساختار پروژه

```
barcood-vpn-bot/
├── main.py              # نقطه ورود و اتصال هندلرها
├── config.py            # تنظیمات و متغیرهای محیطی
├── database.py          # لایه دیتابیس (aiosqlite)
├── keyboards.py         # کیبوردها و دکمه‌ها
├── texts.py             # متن‌های فارسی
├── utils.py             # توابع کمکی (اعداد فارسی، قالب مبلغ و…)
├── handlers_user.py     # شروع، کیف پول، معرفی دوستان، راهنما
├── handlers_shop.py     # فروشگاه و خرید سرویس
├── handlers_support.py  # پشتیبانی دوطرفه
├── handlers_admin.py    # پنل مدیریت
├── handlers_router.py   # مسیریاب پیام‌های چندمرحله‌ای
├── requirements.txt
└── .env.example
```

## 🛠 تکنولوژی‌ها

- [python-telegram-bot v21](https://docs.python-telegram-bot.org/) — ارتباط با تلگرام
- [aiosqlite](https://github.com/omnilib/aiosqlite) — دیتابیس غیرهمگام SQLite
- [python-dotenv](https://github.com/theskumar/python-dotenv) — مدیریت `.env`

## 📝 نکات

- پرداخت به‌صورت **کارت‌به‌کارت دستی** است؛ برای اتصال به درگاه‌هایی مثل زرین‌پال می‌توان جریان شارژ کیف پول را توسعه داد.
- تحویل کانفیگ فعلاً **دستی توسط ادمین** انجام می‌شود؛ برای اتصال خودکار به پنل‌هایی مثل **Marzban** یا **3x-ui** می‌توان ماژول سرویس جداگانه‌ای به `handlers_admin.py` متصل کرد.
- دیتابیس SQLite است و برای مقیاس بزرگ‌تر قابل مهاجرت به PostgreSQL است.
